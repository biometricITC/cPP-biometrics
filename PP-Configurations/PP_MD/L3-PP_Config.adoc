== Introduction

The purpose of a PP-Configuration is to define a Target of Evaluation (TOE) that combines Protection Profiles (PPs) and PP-Modules for various technology types into a single configuration that can be evaluated as a whole. The scope includes the definition of the configuration of a mobile device (a computer in the terms of the PP-Module) that has biometric enrolment and verification capability. The TOE will be defined by a combination of the components described in <<PP-Configuration Components Statement>>.

== PP-Configuration Reference

This PP-Configuration is identified as follows:

* Multi-Assurance PP-Configuration for PAD-L3 Biometric Verification - <<CFG-MDF-BIO-L3>>, {revdate}, Version {revnumber}

== PP-Configuration Components Statement

This PP-Configuration includes the following components:

* PP-Module Base: Protection Profile for Mobile Device Fundamentals, May 1, 2026, Version 4.0. <<PP_MDF>>
* PP-Module: collaborative PP-Module for Biometric enrolment and verification - for unlocking the device - [<<MOD_BIO_V2.1, BIOPP-Module>>], {revdate}, Version {revnumber}
* PP-Module: collaborative PP-Module with PAD-L3 for Biometric verification [<<MOD_L3BIO_V1.0,L3PP-Module>>], {revdate}, Version {revnumber}

== Conformance Statement

Conformance to this PP-Configuration, required for the Security Targets claiming conformance to it, is exact conformance as defined in <<CC1>> and <<CC-E&I>>.

== The Assurance package conformance claim

This PP-Configuration is a Multi-Assurance configuration. This requires conformity to the requirements of the PP-Module Base (<<PP_MDF>>) as well as the requirements of the <<MOD_L3BIO_V1.0>> which is an augmented AVA_VAN.3 requirement targeted in one area.

The global set of SARs are defined in the PP-Module Base, and are consistent with the threats defined in the SPD. The PP-Module defines one enhanced threat, T.Targeted_Attack, a superset of T.Scripted_Attack.

The global set of SARs as defined in the PP-Module Base are consistent with the additional SARs from the PP-Module, in that there is only one additional SAR for the PP-Module (AVA_VAN.3) that is applied only to the sub-TSF of the PP-Module in relation to PAD testing. This application of AVA_VAN.3 to the PP-Module sub-TSF is the intent of the PP-Module and PP-Configuration.
